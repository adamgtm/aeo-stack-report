# Open Source AEO Projects & Resources

The open-source side of AEO/GEO is moving fast. This is the curated landscape — skill packs, frameworks, trackers, publisher-side tooling, and the academic work — for teams that want to build rather than buy. Star counts are a rough proxy for traction, not quality; pick on fit and license.

## Skill packs (Claude Code / Codex / Cursor)

Drop AEO/GEO audits and content workflows straight into a coding agent.

| Project | ★ | What it does |
| ------- | - | ------------ |
| [seo-geo-claude-skills](https://github.com/aaron-he-zhu/seo-geo-claude-skills) | 1,761 | 20 SEO + AEO/GEO skills for Claude Code, Cursor, and Codex. The category leader by stars. |
| [gtm-engineer-skills](https://github.com/onvoyage-ai/gtm-engineer-skills) | 961 | GTM + AEO agent workflows across 13 skill folders. MIT-licensed and clean to fork. |
| [codex-seo](https://github.com/AgriciDaniel/codex-seo) | 170 | Codex-first SEO suite: 26 workflows, 24 agents, DataForSEO / Gemini / Firecrawl integrations. |
| [ultraship](https://github.com/Houseofmvps/ultraship) | 103 | Claude Code plugin with 39 skills and 11 agents. Broader than AEO; useful ecosystem reference. |
| [claude-rank](https://github.com/Houseofmvps/claude-rank) | 34 | Tells you why your site will not get cited by AI, then fixes the issues it finds. |

## Academic research (with code)

The peer-reviewed foundation. AEO/GEO was coined in Princeton and IIT Delhi's [KDD 2024 paper](https://arxiv.org/abs/2311.09735), which built the first benchmark and measured visibility lifts of up to 40%.

| Project | ★ | What it does |
| ------- | - | ------------ |
| [AutoGEO](https://github.com/cxcscmu/AutoGEO) | 152 | ICLR'26 framework that learns AEO/GEO strategies automatically, building on the Princeton paper. |
| [MAGEO](https://github.com/Wu-beining/MAGEO) | 38 | ACL 2026 multi-agent extension: reusable skills for generative-engine optimization. |
| [E-GEO](https://github.com/psbagga17/E-GEO) | 33 | A testbed for AEO/GEO in e-commerce; domain extension of the GEO benchmark. |
| [agentic_geo](https://github.com/AIcling/agentic_geo) | 27 | A self-evolving agentic system for generative-engine optimization (preprint). |
| [research-hub](https://github.com/Wu-beining/generative-engine-optimization-research-hub) | 33 | Aggregator of AEO/GEO/AIO papers, from the MAGEO author. |
