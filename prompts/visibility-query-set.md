# Prompt — Measure your AI-answer visibility (DIY tracker)

Run these queries across the answer engines and record whether you (and competitors) get named. This is the same query shape the AdamGTM Stack uses for its AI-Visibility signal — fork it for your brand.

## Category queries
- best AEO tools 2026
- AEO vs GEO
- how to get cited in ChatGPT
- answer engine optimization guide
- best AEO agencies
- best generative engine optimization platforms

## Competitor queries (swap in your space)
- {competitor} alternatives
- {competitor} competitors

## How to run it
For each query × engine (GPT, Gemini, Perplexity, Claude), capture: was your domain cited? which brands were named? the answer snippet. Store dated → you have a trendline.

A minimal way to run all of it programmatically: one API across engines (e.g. OpenRouter) + a loop. The local-first OSS option is [danishashko/geo-aeo-tracker](https://github.com/danishashko/geo-aeo-tracker); more in `/profiles/aeo-open-source.md`.
